# Erewhon text fonts

The CV uses these four unmodified Erewhon OpenType fonts so it can be built
without installing the fonts on the host system.

- Upstream: https://ctan.org/pkg/erewhon
- Retrieved from: https://github.com/mgubi/vau/tree/9a90c54a5470f09daaa31935fe6a60359341eb73/resources/fonts/truetype/erewhon
- License: SIL Open Font License 1.1; see `OFL.txt`.

The Korean CV also uses unmodified Nanum Myeongjo regular and bold fonts,
copied from the host's installed Naver fonts. See `NanumMyeongjo-OFL.txt`.
Upstream: https://github.com/google/fonts/tree/main/ofl/nanummyeongjo
